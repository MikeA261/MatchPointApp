CAMBIOS REALIZADOS

1. RESERVA DE TURNOS

- Backend/reserve.py ahora pide fecha y horario al usuario autenticado,
  muestra la confirmación y guarda las reservas en Backend/reservations.json.

- Cada reserva conserva usuario, cancha, fecha, horario y estado.

- Se valida el formato de fecha y hora, se rechazan turnos ya ocupados y no se
  permite reservar una cancha bloqueada.

- Cada turno dura una hora; se ofrecen inicios en horas completas dentro del
  horario de atencion de la cancha y se respetan los dias configurados.

- Las reservas activas que se solapan bloquean el turno; al cancelar, vuelve
  a estar disponible.

- El campo "available" no se modifica al reservar un horario: representa si la
  cancha está habilitada en general.

- Backend/menu/menu.py pasa el usuario de la sesión al flujo de reserva.

2. LECTURA Y ESCRITURA DE DATOS

- Backend/reader.py y Backend/writer.py usan rutas construidas desde la
  ubicación de los archivos, para encontrar los JSON dentro de
  Backend/locals_json aunque el programa se ejecute desde otra carpeta.

- La lectura comprueba que los JSON contengan listas de objetos y muestra los
  errores para que el flujo que los usa pueda informarlos.

3. LOGIN Y REGISTRO

- Backend/users/login.py informa si no puede cargar los usuarios, en vez de
  continuar con datos inválidos.
- Backend/register.py maneja errores al leer o guardar, y corrige la llamada
  de retorno al menú para usar my_funtion.

4. COMENTARIOS

- Se agregaron comentarios breves en algunos archivos modificados para
  explicar los ajustes.

- Después de completar la opción 1 o la opción 2, el menú de usuario vuelve
  a mostrarse.
- Tras cancelar una reserva, se solicita ingresar 0 para regresar al menú.
- Backend/menu/menu.py permite ver las reservas activas del usuario y elegir
  una para cancelarla.
- Backend/reserve.py marca la reserva como "cancelled" en lugar de borrarla;
  de ese modo se conserva el historial y el turno vuelve a estar disponible.

- Backend/admins/admin.py valida el inicio de sesión administrativo con DNI y
  contraseña. Todavía no abre un menú posterior.

- La opción "VER TODAS LAS CANCHAS" muestra las habilitadas y no disponibles
  sin iniciar el flujo de reserva.

- En la lista de canchas para reservar, el número seleccionable aparece entre
  paréntesis junto al nombre de la cancha para distinguirlo del teléfono.
  (para evitar confunciones )
