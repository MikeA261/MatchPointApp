### Sobre la aplicacion
<p>Esta aplicacion es creada para resolver el problema en los turnos de las canchas de padel.
    El padel se esta volviendo un deporte popular en Pinamar, cada año hay canchas de padel nuevas
    que la gente no conoce. Un problema frecuente es la cancelacion de turnos a ultimo momento.
    La idea con esta App es que la gente sepa cuando una cancha esta disponible y cuando no, también
    darle comodidad al usuario para reservar un turno de la cancha o darlo de baja.
</p>
